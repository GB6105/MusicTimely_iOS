# 구현 목표 — MusicTimely iOS 코어 (P1~P2)

- 근거: `docs/개발-요구사항-명세서.md`(동작·문구), `docs/design/README.md`(시각). 우선순위는 디자인 문서의 "우선순위 규칙"을 따른다.
- 범위: iOS 클라이언트 앱만. 서버·Android 없음. 호스트 연동은 프로토콜과 독립 실행용 기본 구현만.

## 목표 화면 (피그마 기준)

| 화면 | 명세서 | 피그마 |
|---|---|---|
| 배정 | SCR-01 | `light-01-home` |
| 진행 (D0 추정형) | SCR-02 | `light-02-estimated`, `light-02-running` 레이아웃 |
| 마지막 분량 예고 | FR-017 | `light-02-last-song` |
| 일시정지 | SCR-03 | `light-02-paused` |
| 배정 도달·연장 | SCR-04 | 진행 화면 컴포넌트 재사용 |
| 결과 | SCR-05 | `light-03-result` |
| 음악 선택 시트 | SCR-06 | 디자인 토큰으로 구성 |
| 곡 표시 보정 | SCR-07 | `light-07-correct-song-count` |
| 생각 메모 | SCR-08 | `light-06-capture` |

- 테마: Light(기본), Navy, Dark. 시스템 다크 모드 연동 + 설정에서 선택.
- 톤암: 진행 중 30°, 그 외 0°, 시작·재개 650ms / 멈춤·종료 550ms, Reduce Motion 시 즉시.

## 기능 범위

| 영역 | 포함 | 요구사항 |
|---|---|---|
| 배정 | 작업 제목(선택, 100자), 10/25/40분, 직접 입력 1~240분, D0 환산, 무한 모드 | FR-001~005 |
| 타이머 | 상태 머신 6상태, 멱등 명령, pause/resume, 목표 도달 clamp, +5/+10/+15 연장, 종료 사유 | FR-007~011, §5 |
| 복원 | 단조 시계(sleep 포함) + boot 식별자, 원자 저장, 재부팅·손상·7일 초과 → 복구 선택 | FR-012~013, §8 |
| 곡 환산 | N/R/U/I 계산, 칩 최대 8개, 보정(표시만), 마지막 분량 예고 1회, 곡 표시 OFF, 외부 반복 길이 | FR-014~021, §6 |
| 음악 | 외부 앱 열기(허용 목록, 사용자 탭만), 사용자 https 링크 검증, 실패 폴백, 조건부 고지 1회 | FR-023~026, §7.4 |
| 노이즈 | 화이트/핑크 절차 생성, 명시적 재생, 볼륨 20%, 페이드 1.5s/3s, pause 덕킹 30%, 인터럽트·헤드폰 분리 정지 | FR-027~031 |
| 알림 | 목표 알림 1개(키: 세션·revision), 상태 전이마다 취소·재예약, 잠금 화면에 제목 없음 | §7.1~7.2 |
| 결과·메모 | 배정 vs 세션 시간, 곡 분량 출처 표기, 체감 시간(선택), 메모 500자·20개 | FR-035~037 |
| 설정·삭제 | 평균 곡 길이, 곡 표시, 표시 방식, 모션, 볼륨·페이드, 테마, 알림 상태, 전체 삭제 | FR-038~039 |
| 호스트 | 결과 콜백·이벤트 싱크 프로토콜 + no-op 기본 구현, deliveryId | FR-040, §9.4 |

## 제외 (이유)

- P3 로컬 파일(O0) 재생: 코어 출시 범위 밖. 소스 타입만 정의.
- FR-006 지난 시간 제안: 호스트 taskId 전제. 독립 앱에는 taskId가 없음.
- FR-022 셔플 안내, FR-032 과제 유형별 음원 제안: 근거 데이터가 없는 D0에서는 표시 조건이 성립하지 않음.
- §10 분석 이벤트 전송: 서버 필요.

## 완료 기준

1. `make build`, `make lint` 종료 코드 0.
2. `make test` 종료 코드 0. 도메인 단위 테스트가 QA-02~05, 07~12, 14~17, 20, 41 시나리오를 fake clock으로 재현.
3. UI 테스트: 실행 → 시작 → 일시정지 → 재개 → 마치기 → 결과 → 새 세션 흐름 통과.
4. iPhone 14 Pro 시뮬레이터에서 배정·진행·일시정지·결과·메모·보정·음악 시트·설정 화면을 캡처해 피그마 스크린샷과 비교.
5. 명세서 금지 문구(“곡 들었어”, 가상 곡명, 초과 실패·점수) 0건.
